## Resumen del Problema
Los estudiantes y docentes suelen enfrentar dificultades para centralizar el seguimiento de sus actividades académicas, entrega de tareas, consulta de materias y programación de asesorías. 

Este proyecto resuelve dicha problemática mediante un sistema de escritorio centralizado que permite a los alumnos visualizar sus materias, consultar avisos y paginas institucionales, enviar sus entregas y dar seguimiento a sus pendientes, mientras que a los profesores les facilita la gestión de actividades y visualización de grupos.
